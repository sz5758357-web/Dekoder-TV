# PlayBoxTV Pro

Profesjonalny frontend IPTV w HTML/CSS/JS.

## Pliki
- `index.html`
- `styles.css`
- `app.js`

## Jak uruchomić
Wrzuć pliki na GitHub Pages albo uruchom jako statyczną stronę.

## Funkcje
- lista kanałów
- ulubione
- wyszukiwarka
- zapis ostatniego kanału
- prosty EPG overlay
- ustawienia
- pełny ekran

## Uwaga
To jest odtwarzacz dla legalnych playlist M3U / M3U8.
